# Stormhacks2026
Yo Girt (Vijeta Dhalla, Arianna Suen, Grace Young) submission for StormHacks 2026

# About the Project

## Inspiration

We were inspired by Stormhacks' Dating Show event and the vibrant personalities of the otter mascots. Combining that with inside jokes about SFU life, we created a comedic dating sim that showcases a humorous perspective on the social scene.

## What It Does

**Love Surge** is a dating simulator game where you answer questions asked by characters in a speed-dating format, earning enough points to hopefully win them over!

Our goal is to give players a chance to have fun and get a few laughs from the eccentric and ridiculous characters we dreamed up.

## How We Built It

Love Surge began with a Google Doc outlining the plot, story progression, character details, and each Q&A set.

Using **IBIS Paint**, we created custom sprites and backgrounds for the front end. We then built the game's back-end logic and architecture using **C++ object-oriented programming**, including encapsulation and class polymorphism.

Finally, we converted the game into a front-end HTML implementation with the help of **Claude AI**.

## Challenges We Ran Into

Working on the project throughout the night was our biggest challenge. As the night went on, our skills and cognition rapidly deteriorated. Learning how to pace our naps, manage our energy, and still stay within the deadline was one of the most difficult parts of the hackathon.

## Accomplishments We're Proud Of

We really pushed ourselves throughout the project. Each team member had varying levels of experience with different programming languages, so it was a great accomplishment to combine our skills and tackle a language none of us had much experience with: **HTML**.

Another important point to us was that the **story and artwork were created entirely without AI**.

This was also our first time making a game! Instead of simply writing code to satisfy test cases, we had to think about the **user experience** and how someone would actually interact with and enjoy our project.

## What We Learned

We learned to have more confidence in our existing skills.

Going into this hackathon, we all felt like novices who didn't have much to bring to a competition with seemingly skilled professionals. As the night went on and we became more and more excited about the project we were creating, we realized that we had far more potential than we initially thought.

## What's Next for Love Surge: An SFU Dating Sim

If we had more time, we would implement:

* A feature allowing users to view all of the endings they have achieved
* Save files so users can save and resume their progress
* The ability to load specific game chapters directly from the launch screen
